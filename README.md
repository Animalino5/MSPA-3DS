# MSPA-3DS
A Homestuck (and in the future, other MSPA's) reader for the 3DS


# Huh? What's this?

DId you ever see those Homestuck DS Images and think...

*"MAN I SURE WISH THAT WAS THE COMPLETE WEBCOMIC!"*

Well wish no more! It's here! THE "WHOLE" HOMESTUCK WEBCOMIC ON THE 3DS!!

# How does it work?

It fetches the page content from http://mspa.chadthundercock.com/ and then parses that into jsons and tex files that sit neatly into your SD card, that means 2 things!

* YOUR SD CARD DOES NOT HAVE A 2GB 3DSX WITH ALL HOMESTUCK IMAGES AT ALL TIMES!
* each page takes some time to load. specially with animated gifs.

but its better than nothing alright!!
